## <img src="https://api.iconify.design/lucide:sparkles.svg?color=%23C6F100" width="20" height="20" align="center" /> Overview

**LastWave Reimagined** is a community-maintained fork of [LastWave Native](https://github.com/Clash-Projects/LastWave-native), powered by the global YouTube Music catalog and tailored for listeners who want intelligent recommendations, kinetic visuals, listening analytics, and seamless music tracking.

Built with **Material 3 Expressive**, LastWave Reimagined combines effortless ad-free streaming, an AI-powered smart playlist generator, real-time synchronized karaoke lyrics, a built-in Last.fm scrobbler, local listening analytics that work entirely offline, and synchronized Discord Rich Presence.

---

## <img src="https://api.iconify.design/lucide:sparkles.svg?color=%23C6F100" width="20" height="20" align="center" /> Release v4.3.2 Highlights

- **Listening Insights Dashboard:** Track listening duration (formatted in hours and minutes), total play counts, unique tracks, and unique artists across sessions.
- **Timeframe Filters & Activity Charts:** Interactive filtering by **Today**, **7D**, **30D**, and **All Time** with daily/interval bar charts, Top Tracks lists, and chronological playback history.
- **Offline Local Listening Statistics:** Surfaces real local playback data (plays, tracks, artists, albums) directly on Home and Statistics screens without requiring Last.fm to be connected.
- **Discord Rich Presence Wire Format & Stale-Progress Fix:**
  - Synchronized track titles, artist names, and album artwork on Discord.
  - Pausing playback now strictly nullifies progress timestamps (`timestamps: null`), freezing progress bar advancement in Discord.
  - Explicitly clears presence on natural track completion, manual stop, playback errors, and playback service termination (`clearStopped = true`).
  - Preserves active presence when the app is swiped away from Android Recent Apps if audio playback continues in the foreground service.
- **Room Database Migration (v15 $\to$ v16):** Fully automated, loss-free schema migration (`MIGRATION_15_16`) introducing the `listening_events` table indexed by `played_at`, `track_id`, and `artist`.
- **Verified Test Suite:** Comprehensive test coverage with 577 unit tests passing across Insights, offline local stats, and Discord Presence lifecycle.

## <img src="https://api.iconify.design/lucide:cpu.svg?color=%23C6F100" width="20" height="20" align="center" /> Tech Stack & Architecture

- **Language & UI:** 100% Kotlin + Jetpack Compose (Material 3 Expressive)
- **Audio Engine:** AndroidX Media3 ExoPlayer with lockscreen media controls & Android Auto integration
- **Streaming Catalog:** YouTube Music streaming engine with high-efficiency Opus audio
- **Database & Persistence:** Room DB v16 (`listening_events`, migrations) + Jetpack DataStore
- **Scrobbling & Tracking:** Native OS media session tracking & Last.fm API
- **Discord Integration:** IPC Rich Presence with activity lifecycle state machine
- **Lyrics Engine:** [LRCLIB](https://lrclib.net) millisecond-synchronized lyrics
- **Architecture:** MVVM + Clean Architecture, Room DB, Dagger Hilt, Coroutines & Flow

## <img src="https://api.iconify.design/lucide:rocket.svg?color=%23C6F100" width="20" height="20" align="center" /> Getting Started

1. Check the **[Releases](https://github.com/vedhavyasdavuluri0807/LastWave-Reimagined/releases)** tab for tagged release builds or inspect automated build workflows in the **[Actions](https://github.com/vedhavyasdavuluri0807/LastWave-Reimagined/actions)** tab.
2. Install the APK on your Android device running Android 7.0 (API 24) or higher (Android 10+ recommended).
3. Optional: Connect your Last.fm account in **Settings → Integrations** to unlock external scrobbling, friend listening feeds, and taste mixes. Local playback statistics and Listening Insights work completely offline out of the box without requiring Last.fm.
4. Enjoy ad-free streaming, local playback insights, and real-time synchronized lyrics!

## <img src="https://api.iconify.design/lucide:terminal.svg?color=%23C6F100" width="20" height="20" align="center" /> Building from Source

### Prerequisites
- **JDK:** OpenJDK 17 or higher
- **Android SDK:** Compile SDK 37, target SDK 35, min SDK 29 (Android 10+)
- **Build Tools:** CMake 3.22.1+ and Android NDK (for native components)
- **Git**

### Reproducible Debug Build Instructions

#### On Windows (PowerShell / Command Prompt):
```powershell
# Clone this repository
git clone https://github.com/vedhavyasdavuluri0807/LastWave-Reimagined.git
cd LastWave-Reimagined

# Build the debug APK
.\gradlew.bat :app:assembleDebug

# Generated debug APK output location:
# app\build\outputs\apk\debug\app-debug.apk
```

#### On Linux / macOS:
```bash
# Clone this repository
git clone https://github.com/vedhavyasdavuluri0807/LastWave-Reimagined.git
cd LastWave-Reimagined

# Make gradlew executable and build debug APK
chmod +x gradlew
./gradlew :app:assembleDebug

# Generated debug APK output location:
# app/build/outputs/apk/debug/app-debug.apk
```

### Running Unit Tests
```bash
# Windows
.\gradlew.bat :app:testDebugUnitTest

# Linux / macOS
./gradlew :app:testDebugUnitTest
```

### Release Signing & Security Safeguards

> [!IMPORTANT]
> **Release Signing Requirements & Credential Protection**
>
> Official release APKs require the project's legitimate release-signing configuration (`release` signingConfig with a valid keystore, key alias, and secure signing passwords).
>
> **Security Safeguards:**
> - **Never publish or commit secrets, keystores (`*.jks`, `*.keystore`), private keys, or signing passwords to version control.**
> - Never commit local configuration files containing developer secrets or credentials (e.g. `local.properties`, `.env`, API tokens).
> - Release credentials should be injected securely via environment variables or CI/CD secret management only.
